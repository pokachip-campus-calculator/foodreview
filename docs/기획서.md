# 맛집 리뷰 관리 시스템 기획서

## 1. 서비스 개요
학교 주변 식당을 등록하고 직접 먹어본 사람이 평점과 한줄평을 남기는 콘솔 프로그램.
식당별 평균 평점을 계산해 순위를 보여주고, 관심 있는 식당은 즐겨찾기로 모아 본다.

- 실행 형태: Java 콘솔 프로그램 (웹 화면 없음)
- 사용 기술: JDK 21, MySQL, JDBC, MVC 패턴
- 사용자: 로그인한 회원 1명이 자기 리뷰·즐겨찾기를 관리

## 2. 핵심 엔터티
| 엔터티 | 설명 |
|---|---|
| 회원 (member) | 아이디·비밀번호·닉네임을 가진 사용자 |
| 식당 (restaurant) | 이름·카테고리·주소·전화번호를 가진 가게 |
| 리뷰 (review) | 회원이 식당에 남긴 평점(1~5)과 한줄평 |
| 즐겨찾기 (favorite) | 회원이 찜해 둔 식당 목록 |

### 관계
- 회원 1 : N 리뷰 — 한 회원이 여러 리뷰를 쓴다
- 식당 1 : N 리뷰 — 한 식당에 여러 리뷰가 달린다
- 회원 1 : N 즐겨찾기 / 식당 1 : N 즐겨찾기 — 회원 N:M 식당을 즐겨찾기로 해소
- 같은 회원이 같은 식당에 리뷰는 1개, 즐겨찾기도 1개만 (UNIQUE 제약)

## 3. 기능 목록 (팀원별 담당)
| 담당 | 기능 세트 | 상세 |
|---|---|---|
| 팀장 | 회원 CRUD + 로그인 | 회원가입(C), 내 정보 조회(R), 닉네임·비밀번호 수정(U), 회원 탈퇴(D), 로그인/로그아웃 |
| 팀원 2 | 식당 CRUD + 검색 | 식당 등록(C), 전체 목록·상세 조회(R), 정보 수정(U), 삭제(D), 이름·카테고리 검색 |
| 팀원 3 | 리뷰 CRUD | 리뷰 작성(C), 식당별 리뷰 목록·내 리뷰 목록(R), 리뷰 수정(U), 리뷰 삭제(D) |
| 팀원 4 | 즐겨찾기 + 통계 | 즐겨찾기 추가(C)·목록(R)·해제(D), 평균 평점 순위 TOP 5, 카테고리별 식당 수 |

### 공통 코드 (STEP 4에서 먼저 합침)
- `DBUtil` — db.properties 읽어 Connection 발급
- `Main` / `MainView` — 로그인 전/후 메인 메뉴 분기
- `Session` — 로그인한 회원 정보 보관

## 4. 콘솔 메뉴 구조
```
[로그인 전]
=== 맛집 리뷰 ===
1. 로그인
2. 회원가입
0. 종료

[로그인 후]  (닉네임 님 환영합니다)
=== 메인 메뉴 ===
1. 식당 관리
2. 리뷰 관리
3. 즐겨찾기
4. 통계 보기
5. 내 정보
0. 로그아웃

 1. 식당 관리
    1) 식당 목록 보기      2) 식당 검색(이름/카테고리)
    3) 식당 상세 보기      4) 식당 등록
    5) 식당 수정           6) 식당 삭제        0) 뒤로

 2. 리뷰 관리
    1) 식당 리뷰 보기      2) 리뷰 작성
    3) 내 리뷰 목록        4) 리뷰 수정
    5) 리뷰 삭제           0) 뒤로

 3. 즐겨찾기
    1) 내 즐겨찾기 목록    2) 즐겨찾기 추가
    3) 즐겨찾기 해제       0) 뒤로

 4. 통계 보기
    1) 평균 평점 TOP 5     2) 카테고리별 식당 수
    3) 리뷰 많은 식당 TOP 5                     0) 뒤로

 5. 내 정보
    1) 내 정보 조회        2) 닉네임 수정
    3) 비밀번호 수정       4) 회원 탈퇴        0) 뒤로
```

## 5. 주요 규칙
- 로그인은 DB의 아이디·비밀번호를 비교하는 수준 (암호화·인증메일 없음)
- 리뷰·즐겨찾기는 본인이 쓴 것만 수정·삭제 가능
- 평점은 1~5 정수만 입력 허용, 범위 밖이면 다시 입력
- 식당 삭제 시 딸린 리뷰·즐겨찾기도 함께 삭제 (ON DELETE CASCADE)
- 숫자 입력란에 문자가 들어오면 메뉴로 복귀 (프로그램 종료 금지)

## 6. 제외 기능
결제, 이미지·파일 업로드, 이메일 인증, 지도 연동 — 콘솔·JDBC 범위를 벗어나므로 넣지 않음.
