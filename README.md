# 맛집 리뷰 관리 (콘솔 + JDBC + MVC)

## 실행 방법
1. `sql/schema.sql`, `sql/sample-data.sql` 실행
2. `db.properties.example`를 `db.properties`로 복사 후 계정 입력
3. `./gradlew run` 또는 IDE에서 Main 실행

## 브랜치 규칙
- `main` 발표용 완성본 / `develop` 통합본 / `feature/기능-이름` 개인 작업
- feature -> develop PR, 1명 이상 리뷰 후 병합

## 커밋 규칙
`feat|fix|docs|refactor|sql: 한글 설명`
